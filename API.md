# Банковское MVP — API

Базовый URL: `http://localhost:8080`

## Аутентификация

Для большинства запросов требуется **Bearer Token** (JWT). Токен получается при входе.

### Вход в систему
**POST** `/api/v1/auth/login`  
Тело (JSON):
{
"email": "EMAIL IN ENV",
"password": "PASSWORD IN ENV"
}
Ответ содержит токен, который нужно передавать в заголовке `Authorization: Bearer <token>`.

## Группа Admin (требуется роль ADMIN)

Эндпоинты для управления пользователями, счетами, картами.

### Пользователи

#### Создать пользователя
**POST** `/api/v1/user`  
Тело (JSON):
{
"firstName": "Admin",
"lastName": "Adminov",
"email": "myadmin@example.com",
"phone": "+79991112233",
"identityDocumentNumber": "0000 000001",
"password": "admin123",
"userRole": "ADMIN",
"userStatus": "ACTIVE"
}

#### Получить всех пользователей (с пагинацией)
**GET** `/api/v1/user?page=0&size=100`  
Параметры запроса:
- `page` (целое, по умолчанию 0)
- `size` (целое, по умолчанию 100)

#### Найти пользователя по имени
**GET** `/api/v1/user/find?firstname=Иван&lastname=Иванов&page=0&size=1`  
Параметры запроса:
- `firstname` (строка, обязательно)
- `lastname` (строка, обязательно)
- `page` (целое, опционально)
- `size` (целое, опционально)

#### Обновить пользователя
**PUT** `/api/v1/user/{id}`  
Путь: `id` — идентификатор пользователя.  
Тело (JSON):
{
"firstName": "Иван",
"lastName": "Петров",
"email": "ivan.petrov@example.com",
"phone": "+79998887766",
"identityDocumentNumber": "9876 543210",
"userRole": "ADMIN",
"userStatus": "ACTIVE"
}

#### Удалить пользователя
**DELETE** `/api/v1/user/{id}`  
Путь: `id` — идентификатор пользователя.  
Тело не требуется

---

### Счета и карты (администрирование)

#### Создать счёт
**POST** `/api/v1/account/create`  
Тело (JSON):
{
"userId": 1,
"initialBalance": 150000.00
}

#### Создать карту
**POST** `/api/v1/card`  
Тело (JSON):
{
"userId": 1,
"accountId": 1,
"validityPeriod": "2028-12-31T23:59:59"
}

#### Получить все карты (с пагинацией)
**GET** `/api/v1/card?page=0&size=10`  
Параметры запроса:
- `page` (целое)
- `size` (целое)

#### Активировать карту
**POST** `/api/v1/card/{id}/activate`  
Путь: `id` — идентификатор карты.

#### Заблокировать карту (администратором)
**POST** `/api/v1/card/{id}/block`  
Путь: `id` — идентификатор карты.

#### Удалить карту
**DELETE** `/api/v1/card/{id}`  
Путь: `id` — идентификатор карты.

## Группа User (требуется аутентификация, роль USER)

Эндпоинты для работы пользователя со своими картами.

### Получить свои карты (с поиском и пагинацией)
**GET** `/api/v1/user/cards?search=6716&size=1&page=1`  
Параметры запроса:
- `search` (строка, опционально, поиск по номеру карты)
- `page` (целое, опционально)
- `size` (целое, опционально)

### Запросить блокировку карты
**POST** `/api/v1/user/cards/{cardId}/block-request?userId=1`  
Путь: `cardId` — идентификатор карты.  
Параметры запроса:
- `userId` (целое, идентификатор текущего пользователя)

### Перевод между своими картами
**POST** `/api/v1/user/cards/transfer?fromCardId=2&toCardId=3&amount=1510.00&userId=1`  
Параметры запроса:
- `fromCardId` (целое)
- `toCardId` (целое)
- `amount` (число с плавающей точкой)
- `userId` (целое)

### Проверить баланс карты
**GET** `/api/v1/user/cards/{cardId}/balance?userId=1`  
Путь: `cardId` — идентификатор карты.  
Параметры запроса:
- `userId` (целое)

---

## Примечания

- Все эндпоинты, кроме `/auth/login`, требуют заголовок `Authorization: Bearer <token>`.
- Ответы сервера обычно приходят в формате JSON.
- В случае ошибок возвращаются соответствующие HTTP-статусы и тело с описанием.

Для ручного тестирования рекомендуется использовать Postman или аналогичный инструмент.
